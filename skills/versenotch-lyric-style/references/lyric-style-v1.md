# 声明式歌词样式 v1

状态：VerseNotch 0.2.0 支持本地导入、应用、停用和卸载。规范版本和插件 API 均为 1。发往插件广场的稿件需按官网流程单独审核。

## 包与清单

`.vnplugin` 是 ZIP 文件，根目录放 `manifest.json` 和 `style.json`，不要套一层文件夹。除入口和被背景引用的资源外，不得有额外文件。最多 10 MiB 压缩、30 MiB 解压、100 个文件。图片只允许 `assets/` 下的 PNG/JPEG，单边最多 4096 像素。路径是区分大小写的相对 ASCII 路径，禁止空段、`.`、`..`、反斜杠、符号链接及大小写折叠后重名。

[manifest JSON Schema](manifest-v1.schema.json) 规范字段。ID 用作者控制的反向域名（至少三段），`builtin.*` 和 `com.verse-notch.*` 保留。版本和最低宿主版本用三个非负整数，无前导零；最低宿主版本填 `0.2.0`。样式的 `type` 必须为 `lyric-style`，`entry` 必须为 `style.json`，`permissions` 必须为空。建议使用随技能提供的打包器；客户端接受无注释、非加密的普通 ZIP，条目使用 Stored 或 Deflate，不支持 ZIP64 和数据描述符。

## 样式

[style JSON Schema](style-v1.schema.json) 为字段和范围的来源，禁止未知字段。颜色为 `#RRGGBB` 或 `#RRGGBBAA`。渐变颜色按方向依次等距铺开，图片由宿主按 `fit` 或 `fill` 缩放裁切。逐字高亮仅在宿主已有逐字时间时使用；逐行歌词回退按句。减少动态效果时过渡回退静态。宿主提供时钟、渲染区域和预览歌词；样式不改变窗口尺寸、点击区域、播放状态或用户的歌词数据。样式拒绝脚本、代码、URL、字体和全息布局。

提交前如有支持此契约的客户端，验收长歌词、不同宽度、逐行/逐字、暂停、拖动和减少动效。图片应为自制或可分发素材；发行素材的授权与署名随提交资料提供，不在运行时包里添加未声明文件。静态校验不替代宿主实机验收、完整图像解码、权限审核或市场签名。
