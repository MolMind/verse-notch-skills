# 0.3.0 歌词样式制作与验收

开发宿主的 v4 样例已经可打包和安装。[夜空](../assets/examples/night-sky/)使用 theme.json，三个必填键均为字符串。desktop 支持 none、center、leading，effect 支持 none、stars、starfield、snowfall，scatter 支持 none、line、glyph。none 隐藏对应开关。灵动始终可用；进入全息后保留顶部信息。stars 在灵动和全息画布绘制轻量星点。starfield 和 snowfall 只在全息画布使用宿主的 Metal 粒子渲染。stars、starfield 初次默认开启，snowfall 和散布默认关闭。减少动态效果或关闭特效会移除粒子层，设备无法创建 GPU 管线时保留歌词。

所有歌词包共用 `lyric-style` 类型，浮窗固定展开。v1–v3 包继续使用对应版本的文字绘制能力。v4 包可声明画布、动效和布局。

| 能力 | 作者设计与使用规则 | 实窗验收 |
| --- | --- | --- |
| 灵动 | 使用宿主提供的中层可用矩形与歌词时钟。声明字体、正文锚点、逐字或逐行动画及局部装饰，保持底材和顶栏可独立搭配。为长行、无逐字时间、前奏交接设计布局。 | 在 520、640、740 pt 宽度及明暗底材检查读序、溢出、封面与进度条可读性。菜单栏模式若支持，应单独排版。 |
| 全息 | 为桌面可用区域另做构图，明确视线起点、当前句与相邻句的关系，透明留白与点击穿透由宿主维持。可参考聊天气泡的两侧接唱与怪盗回廊的近远景。 | 从灵动中途切入再退出，检查同一歌词位置、顶部控制和桌面可操作性。换屏后重新布局。 |
| 特效 | 指定效果属于哪一画布、使用哪些宿主算子、开关默认值及静态或低动态替代画面。参考星海游鱼的星场与雪落的粒子，按各主题需要选择。关闭时释放专用资源。 | 同一段歌词对比开关两态，再验证减少动态效果与 GPU 路径不可用时的字形、时间和可读性。关闭后的效果提交数为零。 |
| 随机画布 | 选择逐字或整句为散布单位，提供可读的关闭态。布局由稳定输入产生，同一歌词和尺寸可重现；尺寸改变重新适配，播放帧间保持位置连续。可分别参考跃字与歌词漫游。 | 固定输入截取两次，拖回同一位置、暂停恢复与重开后核对排布。检查长句边缘裁剪、遮挡与阅读顺序，切换开关保留播放位置。 |

为每个主题记录支持的画布、各选项默认值、输入依赖、效果关闭态和减少动态效果的行为。完整迁移覆盖原版实际具备的能力；新作按设计声明能力。客户端仅对当前画布支持的选项提供控件。

制作对照时固定一条有逐字时间的歌词、一条只有逐行时间的长句，以及含前奏与句间空白的片段，记录媒体时间、屏幕尺寸、缩放和动效偏好。用同一包检查卡片预览、灵动实窗与已声明的桌面效果；静态截图核对布局，短录屏核对入场、运动连续性与 seek 后的同步。跨入旧版顶栏的设计需在新中层重排并记录差异。

交付记录区分作者工具预检、上传规则校验、客户端安装和实际播放。记录包摘要、客户端构建、通过的模式与尚待验证的设备，便于复查同一份产物。

## 带相邻句和间奏图集的舞台

开发宿主的 v4 包可在根目录附加 stage.json。desktopFrame 使用桌面可用矩形的千分比，左上为原点；x、y 加宽高须落在画布内。captions 最多六项，cue 选择 previous、current 或 next，分别给出 frame、0 至 100 的 opacity 和 −30 至 30 度的 tilt。缺句时跳过该项。随机画布仅在其分配区域内移动。glyphMotion 可选 glow（高亮发光）、lift（逐字上浮）、reveal（淡入）、wipe（沿字宽扫色）、stagger（交错倾斜进出场，长句分两行）、underline（双行错位，演唱字下方的描线跟随进度）、gather（逐字从八个方向聚合到基线）、drift（在稳定网格中漂移，当前字描框，唱完淡出）或 fall（逐字飘落，句末在 1050 ms 内下沉消融；需要跨句消融时将 previous 和 current 叠放）。ripple 使字形按演唱时间弹入、旋转并产生涟漪。配合 scatter 为 glyph 时，用户可以在有序排版和可复现的逐字散布之间切换。省略 glyphMotion 时沿用基本文字绘制。

## 固定排版

常规文字可在 `theme.json` 声明 `"lineLayout": "single"` 或 `"lineLayout": "double"`。省略时使用单行基础布局。双行将同一句歌词分成左高、右低的两行，在单字歌词时保留一行。双行支持省略 `glyphMotion`，或使用 `glow`、`lift`、`reveal`、`wipe`。宿主按包内布局绘制。

自定义舞台使用 `stage.json` 的 caption 区域安排多行或多句。字形特效可以自带专用构图，例如 `underline` 的双行错位。此类布局由插件设计决定。


gapShots 为空时保留底景。有图集时，宿主在歌词空档按 holdMs 顺序切换镜头，镜头内按 cycleMs 循环播放。系统减少动态效果时取固定帧。图集放在 assets/ 下，PNG 或 JPEG，单边上限 4096 像素，宽高必须分别整除 columns、rows，单包全部间奏图集合计最多 1600 万像素。其他范围见[舞台契约](stage-v4.schema.json)。字幕区和镜头始终经过宿主中层裁剪。

API v4 支持在包内提供 `assets/cover.png` 作为插件库和外观页的静态封面。使用单帧 PNG，宽、高各不超过 1024 像素，文件不超过 1 MiB。封面和演出背景分别制作。

纵向排字可在 theme.json 使用 `glyphMotion: "columns"`。用 stage.json 的 caption.frame 决定排字区域。紧凑窗口每列三个字，高画布每列五个字；每页最多三列，按播放位置翻页，跳播和减少动态效果时保留可读布局。

## 全浮窗覆盖

推荐在 v4 的 `theme.json` 使用 `"windowCoverage": "full"`。背景延伸至顶部两翼和歌词区，宿主裁切轮廓与刘海开口，并绘制封面、曲名、进度和交互按钮。常规歌词和 `stage.json` 的 caption 仍在歌词区排版，避免遮挡播放信息。只需歌词区的包可使用 `"windowCoverage": "lyrics"`，省略时也采用歌词区。

以下 `composition` 可选。每个构图负责自己的文字和装饰布局，要求 `windowCoverage` 为 `full`。包省略 `stage.json`、`glyphMotion` 和 `lineLayout`，`style.json` 使用透明底。

| 构图 | 表现和素材 |
| --- | --- |
| `portrait-chat` | 角色轮换、表情过渡和多句气泡。包内提供 `assets/portraits.png`，3 列表情、4 行角色。 |
| `conversation` | 相邻歌词交替左右入场，全息模式显示连续对话。使用相同规格的头像图集。 |
| `receding-tiles` | 字组按歌词时间交替横竖入场，已唱字组缩小远去。 |
| `cutout` | 当前字推动红色斜切字卡，其他字保持黑底白字。 |
| `rain-footsteps` | 雨纹、行走足迹与纵排歌词。提供 `assets/paper.png` 及 `assets/footsteps.png`，足迹图集为 6 列、4 行。 |
| `star-fish` | 分层星场、线描游鱼与逐字变色。配合 `effect: "starfield"` 可在全息模式使用 GPU 星场。 |
| `gathering-ink` | 字形聚向基线，运用全息浅色环境下的深灰和深蓝配色。 |
| `drifting-ink` | 字形在稳定网格漂移，当前字带蓝色选框，唱完逐步淡出。 |
| `lyric-camera` | 在整首歌的字块间移动镜头，支持 `scatter: "line"` 固定种子的随机排版。 |
| `paper-journey` | 纸面、墨字和蓝字。间奏素材为 `assets/back.jpg`（4×6）和 `assets/steps.jpg`（4×9），全息演唱时只留下文字。 |
| `fog-glass` | 雾面玻璃、雨滴和逐笔手写。使用 `assets/amber-lights.jpg`、`assets/condensation.jpg`、`assets/elevated-night.jpg` 及 `assets/finger-strokes.json`，附上 `assets/notice.txt`、`assets/copying.txt`、`assets/arphicpl.txt`。 |

构图图片使用声明路径对应的 PNG 或 JPEG，单边不超过 4096 像素且总计不超过 400 万像素。预览时分别检查 520、640、740 pt 的顶部控件可读性、长句、暂停、拖动换句与减少动态效果。

笔画表每项的键为字符，值为 Base64 编码的 UTF-8 JSON，解码后为按书写顺序的折线数组，每个采样点由两个 0–1024 整数组成。未收录的字符由宿主回退到字体轮廓。
