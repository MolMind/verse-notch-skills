# 设计歌词或封面自动获取

每次设计选择歌词或封面。同一需求涉及两种能力时，分别交付两份 Markdown 提案。在线补全契约和市场安装尚未开放。

1. 核对来源文档、许可范围、请求限制和内容归属。记录允许接收的曲目信息、用途、缓存时长，以及来源不可用时的行为。请求只使用匹配所需标签，无需平台登录凭证。
2. 歌词优先保留手工绑定、本地歌词及内嵌数据。说明候选匹配所用的标题、完整艺人、时长和可用专辑，保留现场、混音及合唱版本差异。说明逐行与逐字兼容行为，缺少时间轴时保留原始精度。
3. 封面优先保留内嵌和用户指定图片。说明艺人、专辑、发行版本及必要的曲目验证条件，多候选无法判定时保留缺失状态。
4. 区分匹配、无结果、歧义、暂时失败和停用五种状态。分别定义缓存、重试、取消与清理规则。暂时失败仍可重试。

## 交付

提供来源与许可表、匹配顺序、缓存规则、请求字段及测试表。测试表包含输入标签、候选、期望状态和是否写缓存。至少覆盖同名不同艺人、合唱或现场版、本地资料优先、来源失败和停用期间的迟到回包。
