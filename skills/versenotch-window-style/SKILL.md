# 设计浮窗样式

浮窗样式插件契约尚未开放。交付 Markdown 预设提案，逐项标明宿主已支持与待扩展的能力。

1. 确认使用场景和优先目标，例如桌面工作时持续显示歌词或随节奏轻量共振。分别记录宽度、高度、材质、圆角、样式层透明度和共振的目标值。宿主允许的枚举和范围以目标版本文档为准。宽高注明 pt 或比例。
2. 将浮窗轮廓与歌词绘制分别描述。规划控件避让、长歌词裁切和材质下的可读性。桌面全息舞台与浮窗分别给出表现。
3. 写明暂停、拖动播放、开启系统「减少动态效果」时的表现，以及材质或渲染能力不可用时采用的宿主默认值。

## 交付

提供预设参数表，以及「场景、预期布局、回退结果」验收表。至少覆盖有刘海与无刘海、菜单栏齐平、窄宽、长歌词、切换显示器、减少动态效果和恢复默认样式。若有示意图，用原创示例歌词并标明演示尺寸。
