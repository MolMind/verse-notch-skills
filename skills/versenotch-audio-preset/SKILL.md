# 设计音质调节预设

音质预设插件契约尚未开放。交付 Markdown 音频预设提案。参数是设计建议，可用的滤波器、级数、上下限和播放链路由目标宿主确认。

1. 确认适用内容、听感目标、输出设备和播放路径。分别标出本地文件与流播的处理位置，宿主支持尚未确认的组合注明待测。
2. 列出信号链及参数，例如前级增益、均衡、限幅和最终输出。每段写明实际单位和作用，例如频率 Hz、增益 dB、Q 或带宽。检查频率与采样率、可用余量和多段叠加增益。旁路时回到宿主原有链路。
3. 记录启停、拖动、切歌和切换输出设备时的过渡策略。为不支持的格式、超范围参数、资源不足和处理失败指定回退。主观音色比较使用匹配电平的旁路对照。

## 交付

提供预设目的、信号链表、带单位的参数表、路径兼容表及实测步骤。至少覆盖削波与峰值、启停爆音、旁路恢复、采样率或设备切换、CPU 开销，以及无法处理的流播路径。未实际测量的结果标记为待验证。
